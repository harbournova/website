01 / THE IDEA

Keep the spirit.
Move the language forward.

HarbourNova is an independent project led by Eric Lendvai. It builds on Harbour’s foundations while making room for deliberate changes to the language, runtime, and developer experience.

The aim is evolution, not compatibility at any cost: retain the productive approach of the xBase family of languages, and rethink inherited constraints.

01

Familiar foundations

A practical, readable approach to programming, with its roots in Harbour and the wider xBase family of languages.

02

Deliberate evolution

A distinct language direction rather than a promise to run every existing Harbour program unchanged.

03

Developer-focused

A compiler, tooling, and application-development story being shaped together—not just a new name.

04 / GOOD QUESTIONS

Before you
get started.

A few things to know at this stage of the project.

Can I download HarbourNova now?

Not yet. The compiler and HN Web Framework are still in development. There is no public compiler or framework release to download. You can join the community for discussion and announcements now.

Will the HarbourNova compiler be free?

Yes. The HarbourNova compiler is being developed for distribution free of charge. License terms and applicable notices will accompany the actual release. A public download is not available yet.

Are the source repositories public?

The core and HN Web Framework development repositories are currently private. The public HarbourNova repository is open now for design documents and will host future HN downloads. No public compiler release is available yet. Joining the Google Group does not grant access to private repositories.

What does “xBase” mean?

Here, xBase refers to a family of related programming languages, including Harbour, Clipper, and FoxPro. It describes the language family, not a separate HarbourNova product or a promise of compatibility with every language in that family.

Is this a drop-in replacement for Harbour?

No. HarbourNova builds on Harbour’s foundations but follows its own language and runtime direction. Existing Harbour code should not be assumed to compile or behave unchanged.

How do I join or ask a question?

Open the HarbourNova users group and follow the membership prompts shown by Google Groups. Use the group for project questions, ideas, and feedback.

When will the first public release be available?

No public release date has been announced. When a release is ready, this website and the community group will point to the distribution repository, versioned downloads, documentation, and license information.

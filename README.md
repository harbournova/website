# HarbourNova Under Construction Website

Minimal static placeholder website for GitHub Pages.

## Files

- `index.html` - single landing page
- `assets/site.css` - styling
- `assets/favicon.svg` - simple favicon
- `.nojekyll` - disables Jekyll processing on GitHub Pages

## Publishing on GitHub Pages

1. Copy these files to the root of the GitHub repository used for the website.
2. Commit and push to GitHub.
3. In GitHub, open the repository settings.
4. Go to **Pages**.
5. Select the branch and folder to publish from, usually `main` and `/root`.

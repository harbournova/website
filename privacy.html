HARBOURNOVA / SITE INFORMATION

About this site & privacy.

This is the project website for HarbourNova, maintained by Eric Lendvai. It introduces a project in development and links to community discussions and public design documents. It does not currently distribute the HarbourNova compiler or HN Web Framework.

Project status and future releases

The HarbourNova compiler is being developed for free distribution. The public HarbourNova repository on GitHub contains design documents now and will host future HN downloads. No public compiler release is available yet. The core and HN Web Framework development repositories remain private. Software licenses and applicable notices will accompany actual releases.

A simple project website

This site’s pages do not include analytics scripts, advertising trackers, account registration, or a contact form. The site code does not set cookies or use browser local storage. Fonts and brand images are served with the site rather than loaded from a separate font or image service.

Reading this website does not require a HarbourNova account. Community participation uses Google Groups and its separate membership process.

Hosting and external services

The site is hosted through GitHub Pages. Hosting and network providers may process information needed to deliver pages, such as web requests. Their handling of that information is separate from the site code described above.

Community links take you to Google Groups, an external service. Google may require sign-in and may use cookies or other information under its own policies. Group membership and message visibility are controlled by Google Groups and the group’s settings, not by this website.

Design-document and future-download links take you to the public HarbourNova repository on GitHub. GitHub is an external service with its own policies.

Posting in the community

Before posting, check the group’s current visibility and membership settings. Do not include passwords, credentials, confidential source code, or other information you do not intend to share with the group’s audience.

Project questions

Please use the HarbourNova users group for questions about the project or this website.

Names and artwork

HarbourNova™ is a trademark of Eric Lendvai. On this site, “xBase” describes the family of related programming languages that includes Harbour; it is not used as the name of a HarbourNova product. Other names identify their respective projects and services. References to other projects, languages, or services do not imply their sponsorship or endorsement of HarbourNova.
